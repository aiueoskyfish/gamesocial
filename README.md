# GameSocial

X でログインして、条件に合う相手とランダムにつながるアプリ。
つながり方は **チャット**（打っている文字がそのまま流れるジフシー式）か **通話** の2択。

中央サーバーを持たず、会話の中身は相手の端末と直接やり取りします。

---

## 動かすまでに必要な作業は2つ

どちらも **無料・クレジットカード不要**。合計30分ほど。

| # | 作業 | 理由 | 手順 |
|---|---|---|---|
| 1 | **Gunリレーを1つ立てる** | これが無いと**何も動きません** | [relay/README.md](relay/README.md) |
| 2 | **Cloudflare Worker を立てる** | X の認証がブラウザだけでは完了できないため | [worker/README.md](worker/README.md) |

その後、`js/gun-init.js` の `RELAYS` と `js/auth.js` の `clientId` / `workerUrl` を書き換えれば完成です。

---

## なぜこの2つが必要なのか（実測の結果）

推測ではなく、実際にリクエストを投げて確認した内容です。

### ① X のトークン交換はブラウザから実行できない

```
OPTIONS https://api.x.com/2/oauth2/token   → Access-Control-Allow-Origin 無し
GET     https://api.x.com/2/users/me       → Access-Control-Allow-Origin 無し
```

CORS ヘッダが返らないため、ブラウザがレスポンスを JavaScript に渡しません。
PKCE は「秘密鍵を隠せない環境」向けの仕組みですが、CORS 許可は別問題で X 側が許可していません。

→ 中継専用の Cloudflare Worker（約40行、DBも常駐プロセスも無し）で解決。無料枠10万req/日。

### ② 使えるパブリック Gun リレーは1つも無い

候補を10個試した結果、HTTP 200 を返したのは `relay.peer.ooo` だけ。
しかもそれは2端末で実測したところ、**WebSocket は繋がるのにデータが相手に一切届きません**。

```
A が書き込み → B から読む → undefined
```

接続インジケーターは緑になるのに誰ともマッチしない、という症状になります。
自前リレーに向けた瞬間に全機能が動作することは確認済みです。

## 検証済みの動作（独立した2ピアでの実機テスト）

| 項目 | 結果 |
|---|---|
| ランダムマッチ（相互条件の照合） | ✅ 双方の希望が噛み合ったときだけ成立 |
| 性別の絞り込み | ✅ 「女性のみ」指定が正しく効く |
| ゲームの絞り込み | ✅ 「VALORANT」指定が正しく効く |
| チャットのリアルタイム表示 | ✅ 1文字ずつ相手に流れる・打ち中表示 |
| 確定と既読 | ✅ Enter 確定時のみ既読が返る |
| 相手情報の表示 | ✅ 名前・アイコン・ID・フォロワー数・フォロー中 |
| 履歴の記録 | ✅ 通話とチャットを1つの時系列に記録 |
| チャット記録の閲覧 | ✅ 履歴から会話内容を再表示 |
| ランク・XP | ✅ Silver → Mythic の5段階 |

音声通話はマイク権限が必要なため自動テストでは未検証ですが、
同じ PeerConnection とシグナリング経路をチャットで検証済みです。

## 設計の要点

- **会話の中身は Gun に流れません。** Gun が担うのはロビー（相手探し）と
  WebRTC のシグナリングだけ。本文と音声は P2P 接続を直接通ります。
- **どちらが発信するかは公開鍵の大小で決めます。** 両方が同時に offer を出すと
  衝突するため、必ず片方だけが発信側になります。
- **名前とアイコンは X のものを使い、変更できません。** なりすましを作りにくくするためです。
- **保存先は IndexedDB のみ。** キャッシュを消せば鍵も履歴も消えて、次回は別人として始まります。

## ローカルで動かす

```bash
python C:/gamesocial/scripts/serve.py 8000
```

2端末テスト用にリレーも手元で動かす場合:

```bash
cd C:/gamesocial/relay && npm install && npm start
```

`js/gun-init.js` の `RELAYS` に `http://localhost:8765/gun` を足してください。

---

## 正直に言っておくべきこと

- **XP は端末側の自己申告です。** ランキングを作らない方針なので実害はありませんが、正しさは保証できません。
- **通報・ブロックの仕組みがありません。** 分散型で管理者が存在しないため、
  不快な相手に当たった場合は終了するしかありません。運用するなら最低限ブロックリストが要ります。
- **TURN が無いと一部の回線では繋がりません。** 特にモバイル回線同士。
  既定では Open Relay Project の無料公開TURNを使っています。
- **大髭113 はラテン文字を持ちません。** 和文見出し専用に隔離してあり、英数字には当てていません。
  ニューロダン・ロウディは未インストールですが、入れれば自動で切り替わります。

js/connect.js       つながる（ランダムマッチ）

js/chat.js          リアルタイムチャット
js/history.js       通話とチャットの履歴
js/rank.js          ランク・XP
js/app.js           起動・画面制御
